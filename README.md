# JAVÈRA – A Digital Museum of Java Island

**JAVÈRA** is a digital museum website dedicated to preserving and introducing the rich cultural heritage of Java Island, Indonesia.

Through an interactive digital experience, JAVÈRA invites visitors to explore traditional arts, cultural expressions, historical landmarks, and creative works that represent the identity of each region.

## About the Project

JAVÈRA is designed as a digital platform that brings Indonesian culture closer to the younger generation. It provides a space to discover, appreciate, and learn about the artistic and cultural diversity of Java Island.

The website combines cultural storytelling with a modern visual interface inspired by traditional Indonesian aesthetics, featuring earthy colors, golden accents, and batik-inspired decorative elements.

## Features

- **Home** – Introduces JAVÈRA and its digital museum concept.
- **Explore** – Discover the cultural heritage and artistic identity of different regions across Java Island.
- **Collection** – Browse a curated collection of Indonesian artworks, including textiles, patterns, performing arts, crafts, architecture, and paintings.
- **Art Exhibition** – Explore cultural artworks through a digital exhibition experience.
- **Cultural Quiz** – Test your knowledge of Indonesian culture through an educational quiz.

## Tech Stack

The project is built using:

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript** – Interactive elements and website functionality.
- **Google Fonts** – Playfair Display and Plus Jakarta Sans for typography.

## Getting Started

Follow these steps to run JAVÈRA locally:

**1. Clone the repository**

```bash
git clone https://github.com/username/JAVERA.git
```

**2. Navigate to the project directory**

```bash
cd JAVERA
```

**3. Open the project**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code for a better development experience.

## Design Concept

JAVÈRA's visual identity is inspired by the beauty of traditional Indonesian art and cultural heritage.

The design incorporates:

- **Earthy Brown** – Represents warmth, tradition, and cultural depth.
- **Golden Accents** – Symbolize artistic value and cultural richness.
- **Playfair Display** – Creates an elegant and timeless editorial appearance.
- **Batik-inspired Patterns** – Reflect Indonesia's traditional craftsmanship and artistic identity.

## Project Goals

1. Introduce the cultural diversity of Java Island through a digital platform.
2. Preserve and promote traditional Indonesian art and heritage.
3. Create an engaging and accessible cultural learning experience.
4. Encourage younger generations to appreciate Indonesia's cultural identity.
